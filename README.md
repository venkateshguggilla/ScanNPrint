# ScanNPrint

Scan with the connected scanner, save scans as PDF or images, print them, and compose output pages side by side: choose a paper size such as A4, select part of each scan like cropping, straighten it if it's crooked, and arrange the parts on the page to print or save as PDF. Layouts are saved as `.snp` projects.

## Mac

Download `ScanNPrint-<version>.dmg` from [Releases](../../releases), open it and drag ScanNPrint to Applications. Runs on macOS 14 or later, on Apple silicon (M1 and later) and Intel Macs.

Building from source: see [mac/README.md](mac/README.md).

## Windows

The Windows version (WPF, .NET 10) uses the same `.snp` project format; its source lives in `windows/` once added.
